# KAIRO v1.0.0

KAIRO — Local Runtime Manager for Windows

## Downloads

### Windows 64-bit
KAIRO-Setup-1.0.0-x64.exe

For modern 64-bit Windows systems.

### Windows 32-bit
KAIRO-Setup-1.0.0-x86.exe

For 32-bit Windows systems.

## Highlights

- Generic local service management
- Add, edit, and delete services
- Start, stop, and restart services
- Process monitoring
- PID tracking
- Port readiness detection
- Windows Auto Start
- Automatic service restart
- System Tray
- Logs
- Persistent configuration

2. Click **"Choose a tag"** → select the **existing** tag `v1.0.0` (do not create a new tag)
3. Release title: `KAIRO v1.0.0`
4. Paste the description block above (between the two `---` lines)
5. Drag and drop BOTH files from the local `installers/` folder:
   - `KAIRO-Setup-1.0.0-x64.exe` (4,723,782 bytes)
